# Vestiges

An endless RPG built on vanilla Minecraft (Fabric, Minecraft 26.3, Java 25). The character is the core: explore, fight and build like
vanilla, earn automation through levels and discoveries, grow settlements full of workers, run portal dungeons of rising difficulty, and
face 24 dragons to learn the truth about the cycle.

Status: **M0 Foundation** (project setup, config, datapack content loading, networking, the hub shell, the look-at HUD, admin commands).

- Build: `dev build` (needs a JDK 25 in `%USERPROFILE%\.jdks`).
- Design: `docs/design-log.md`. Lore: `docs/lore/`.
