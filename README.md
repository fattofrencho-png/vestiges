# Vestiges

An endless RPG built on vanilla Minecraft (Fabric, Minecraft 26.3, Java 25). The character is the core: explore, fight and build like
vanilla, earn automation through levels and discoveries, grow settlements full of workers, run portal dungeons of rising difficulty, and
face 24 dragons to learn the truth about the cycle.

Status: in development, heading for version 0.1 (the first playable release). Built so far: the foundation and feature switches with a welcome page,
map and waystones, character (levels, passive trees, gear), inventory (extra slots, crafting table slot, Bank, shulker boxes), mobs and loot,
Codex and farming, feats and settlements, optional quests, the Vestiges world type (named continents), villagers (names, a library, a trade
screen, the Wandering Trader), gravestones, small portal dungeons (Overgrown, Trial and End themes) and the reworked Mending (a one-time
safety net, repaired at an anvil). In progress: the first dragons. Later: workers, blueprints, full dungeons, the other dragons and the ending.

- Build: `dev build` (needs a JDK 25 in `%USERPROFILE%\.jdks`). Checks: `dev test`, and `powershell -File tools\run_all.ps1` for every real-game suite.
- Design: `docs/design-log.md`. Lore: `docs/lore/`. Testing: `docs/testing-plan.md`.
